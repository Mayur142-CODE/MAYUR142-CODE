## 🎤 KARA-Q

### AI Powered Karaoke Queue Management Platform

<p align="center">

<img src="https://img.shields.io/badge/React-61DAFB?style=for-the-badge&logo=react&logoColor=black"/>

<img src="https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white"/>

<img src="https://img.shields.io/badge/Supabase-3FCF8E?style=for-the-badge&logo=supabase&logoColor=white"/>

<img src="https://img.shields.io/badge/Express-000000?style=for-the-badge&logo=express"/>

<img src="https://img.shields.io/badge/PWA-5A0FC8?style=for-the-badge"/>

</p>

### ✨ About

KARA-Q is a modern karaoke event management platform designed for karaoke clubs, music events, and live performances.

It enables singers to join events using a unique code, manage song queues, and allows admins to control performances in real time.

### 🌟 Features

- 🎶 Live Queue Management
- 👨‍💼 Admin Dashboard
- 🎤 Singer Registration
- 📺 YouTube Integration
- 📱 Mobile Responsive
- 🌐 Progressive Web App
- ⚡ Real-time Synchronization
- 🔐 Authentication

### 🏗 Architecture

```
React
     │
TypeScript
     │
Express API
     │
Supabase
     │
PostgreSQL
```
